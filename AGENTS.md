# Token Run Hybrid agent rules
1. Work incrementally and preserve existing functionality.
2. Inspect the repository before modifying files.
3. Never claim a build or test passed without executing it.
4. Never fabricate completed assets, integrations, or deployment results.
5. Avoid unnecessary dependencies.
6. Keep compatible with the selected Unity version.
7. Use original or properly licensed assets.
8. Separate client and server authority. Phase 1 is local only.
9. Never commit secrets.
10. Never deploy production or mainnet without approval.
11. Document changes and remaining limitations.
12. Do not implement future phases without authorization.
13. Keep gameplay playable without blockchain.
14. Prioritize gameplay quality over speculative token features.
